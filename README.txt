YASH RESIDENCY — LANDING PAGE PROJECT
=====================================

FILES
- index.html       Main landing page
- css/style.css    All styling and responsive layouts
- js/script.js     Mobile menu, scroll reveal animations and image loading
- images/          Add your hotel photographs here

HOW TO PREVIEW
1. Extract the ZIP folder.
2. Keep the folder structure unchanged.
3. Double-click index.html to open it in your browser.
4. For WordPress, upload the project files to your hosting or use the HTML/CSS/JS in your preferred setup.

HOW TO ADD YOUR PHOTOS
Add/rename your photos to these exact filenames:
- images/hero.jpg                 Main hero/banner photo
- images/hotel-exterior.jpg       About section photo
- images/deluxe-room.jpg          Deluxe room photo
- images/premium-room.jpg         Premium room photo
- images/gallery/gallery-1.jpg    Gallery photo 1
- images/gallery/gallery-2.jpg    Gallery photo 2
- images/gallery/gallery-3.jpg    Gallery photo 3
- images/gallery/gallery-4.jpg    Gallery photo 4
- images/booking-bg.jpg           Optional booking section background

The image areas show neutral placeholders until matching files are added.
Use JPG, JPEG or PNG; if using PNG, either convert to JPG or update the filename in index.html.
Use compressed images for faster loading. Suggested: hero 1600px wide; room/gallery photos 1000–1400px wide.
